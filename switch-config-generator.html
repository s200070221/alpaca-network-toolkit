Interface 設定

🔧 找不到 IP 欄位？點此看如何手動加入（含次要 IP）

本工具的表單目前不提供 Interface／VLAN 的 IP 輸入欄位（僅能透過「匯入既有設定檔」從已有 IP 的設定檔回填）；如需設定或新增 IP（含次要 IP／Secondary IP），請在下方產生設定文字後直接手動編輯，以下為 4 家常見廠牌的參考語法：

--- Cisco IOS-XE ---
interface GigabitEthernet1/0/1
 ip address 192.168.1.1 255.255.255.0
 ip address 192.168.2.1 255.255.255.0 secondary

--- HPE Comware（僅 VLAN-interface／Loopback，官方文件未涵蓋一般物理埠）---
interface Vlan-interface10
 ip address 192.168.1.1 255.255.255.0
 ip address 192.168.2.1 255.255.255.0 sub

--- Aruba CX (AOS-CX) ---
interface vlan 10
 ip address 192.168.1.1/24
 ip address 192.168.2.1/24 secondary

--- FortiSwitch ---
config system interface
 edit "vlan10"
  set ip 192.168.1.1 255.255.255.0
  set secondary-IP enable
  config secondaryip
   edit 1
    set ip 192.168.2.1 255.255.255.0
   next
  end
 next
end
